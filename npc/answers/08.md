# 演習 08 の答え: NPC の PR に仕込んだ欠陥

NPC の PR の筋書き: 「お知らせを 1 件追加しました」と言いながら、CSS と設定ファイルとエディタ設定も触っている。
欠陥は 10 個。すべて CI (`check`) を通る。「CI が緑でも人が見るものがある」を体験させるための構成。
ID の意味は `docs/review-ids.md`。組織の観点集があれば、同じ ID の本文を正とする。

## 読み合わせ (対面 3) の進め方

1. 受講者が付けたコメントを上から順に読み、1 つずつ表に写す (10 分)
2. 見逃した欠陥を進行役が指し、「どこを見れば気づけたか」を一緒に言葉にする (20 分)
3. MUST の基準 (マージすると壊れる / 環境差で動かない / 運用ルール違反 / 要件との不一致が完了扱いになる / セキュリティ) を 1 つずつ当ててみる (10 分)
4. 受講者が Request changes を出し直す。NPC の PR は close する (マージしない)
