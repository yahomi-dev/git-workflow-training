# 砂場: ひだまり図書室の案内サイト

Git の研修で手を動かすための小さな静的サイト。HTML と CSS だけで、ビルドは要らない。
`index.html` をブラウザで開けば確認できる (`docker compose up` で `http://localhost:8080` に出すこともできる。演習 11)。

- **ひだまり図書室は架空の施設**。登場する本、お知らせ、住所もすべて架空で、実在の組織・人物・作品とは関係がない
- 学ぶ対象はサイトではなく **変更をチームで取り込む流れ**。見た目を良くする演習ではない
- 各クエストの本文が「どのファイルのどの行を何に変えるか」を指示する。指示どおりに変えると、同僚役 (NPC) の変更とぶつかるように作ってある
- このディレクトリは `baseline` タグの状態が初期状態。次の受講者に回すときは `scripts/reset.sh` で戻す

## 構成

| ファイル | 中身 | 演習で触るところ |

| `index.html` | 開館時間の表、お知らせ、おすすめ本、フッタ | 開館時間の土曜行 (06)、お知らせ (04, 05, 08)、おすすめ本の 1 冊目 (07, 09)、フッタのリンク (10) |
| `style.css` | 最小の装飾 | 08 (NPC の PR が触る) |
| `img/logo.svg` | ロゴ 1 枚 | - |
