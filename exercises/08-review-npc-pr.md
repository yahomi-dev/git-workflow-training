# quest-08: 同僚の {{pr}} をレビューする

<!-- issue:start -->
## 状況

同僚 (NPC) が {{pr}} 「お知らせに読書会の案内を 1 件追加する」を出し、あなたがレビュアーに指名されました。
{{ci}} は緑です。それでも、この {{pr}} には **欠陥が 10 個** 仕込まれています。何個見つけられるでしょうか。
見つけたものは、観点の ID と温度感を付けてコメントします。終わったら **対面 3** で進行役と読み合わせます。

## やること

1. [レビュー観点の ID](../docs/review-ids.md) を読む。温度感タグ (MUST / SHOULD / NITS / Q) と、MUST にする 5 つの基準を頭に入れる
2. Pull requests (GitLab では Merge requests) から、ラベル `npc` の {{pr}} を開く
3. **本文と差分を突き合わせる**。「変更内容」に書いてあるファイルと、Files changed の一覧は一致しているか
4. Files changed を **上から 1 ファイルずつ** 読む。新しく増えたファイルは、そもそもコミットしてよいものか
5. 動かして見る。ローカルに取り出してブラウザで開く

   ```bash
   {{pr_checkout}} <番号>
   explorer.exe .
   ```

   見た目で分かる欠陥もある (背景色が付くはずの箱、画像、文言)。見終わったら `git switch main` で戻る

6. 見つけたものを **1 コメント 1 論点** で、該当する行に書く。形は次のとおり

   ```text
   [SHOULD] STATIC-10 画像に内容を表す alt がありません。
   読書会の案内の画像なので、装飾ではなく意味があります。alt="読書会のご案内" のように内容を書いてください。
   ```

   - 温度感 + ID + 一言 (1 行目)、根拠と直し方 (2 行目以降)
   - MUST には理由を括弧で添える: `[MUST] (秘密がリポジトリに入るため)`
7. 全部書いたら、Review changes から **{{request_changes}}** でまとめる。まとめのコメントに、指摘の数と、最初に直してほしいものを 1 行
8. 対面 3 で進行役と読み合わせる。見逃したものを一緒に表にする。この {{pr}} はマージしない (進行役が close する)

## 完了条件

- [ ] 5 件以上の指摘を、1 コメント 1 論点で行に付けた
- [ ] すべてのコメントに温度感タグと観点の ID がある
- [ ] MUST を 1 件以上付け、理由を括弧で添えた
- [ ] {{request_changes}} でレビューを送った
- [ ] 対面 3 で見逃し表を作った

## 参考

- [レビュー観点の ID](../docs/review-ids.md)
- [{{platform}} での操作の 1 枚](../{{platform_doc}}) の「レビューの操作」
- `npc/answers/` は **対面 3 が終わるまで開かない**

## 詰まったら

「気になるが ID が分からない」ものは、`[Q]` を付けて書いてよい。ID は読み合わせで一緒に付ける。

## 進行役メモ

- **対面 3 の 2〜3 日前** に Actions > `npc-pr` > Run workflow (quest = 08) を起動する。`TRAINEE_LOGIN` が設定されていれば受講者がレビュアーに指名される。起動後、{{pr}} が開いたことと `check` が緑であることを確かめる
- NPC の {{pr}} の欠陥一覧と読み合わせの進め方は `npc/answers/08.md`。見逃し表は進行役の手元に (progress-template 2b 節)
- 対面 3 (1 時間) の流し方: 受講者のコメントを上から表に写す (10 分) -> 見逃したものを「どこを見れば気づけたか」と一緒に言葉にする (20 分) -> MUST の 5 基準を 1 つずつ当てる (10 分) -> 受講者が {{request_changes}} を出し直す (10 分) -> 残りは質問
- 終わったら NPC の {{pr}} を close し、ブランチを消す (`npc/08-*`)。やり直すときは消してから再起動
- 受講者が 10 個全部を見つける必要はない。見るのは、MUST を拾えたか、ID と温度感を付ける習慣が付いたか、本文と差分を突き合わせたか
- 到達チェック **T-4**
